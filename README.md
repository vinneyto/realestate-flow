# Маршрут сделки

Интерактивное руководство риелтора по подготовке сделки с недвижимостью. Next.js 16, TypeScript, Tailwind CSS 4, компоненты в стиле shadcn/ui New York (как в `vinneyto/camera_path`). Светлая и тёмная темы, мобильная и десктопная верстка.

## Запуск

```bash
npm install
npm run dev
```

Откройте `http://localhost:3000`. Для проверки: `npm test`, `npm run lint`, `npm run build`.

## Как работает маршрут

- Вопросы ведут к следующей карточке; подпись каждого ответа объясняет переход.
- Основание права выбирается из девяти веток, затем маршрут возвращается к общим шагам.
- Кнопка «Назад» идёт по фактическому пути. При возврате в ранний этап более поздние ответы удаляются.
- Состояние хранится в коротких кодах карточек, указанных в интерфейсе: например, `?path=C01.C02.C03&done=C02.1`. Кнопка «Поделиться» копирует ссылку; открытие ссылки восстанавливает маршрут. Старые ссылки с `s` и длинными названиями шагов тоже открываются и автоматически переводятся в новый формат. Кнопки браузера «Назад» и «Вперёд» также работают.
- В адрес не записываются имена, документы, адреса объектов, суммы и иные личные сведения. Ссылка всё же раскрывает этап и выбранные ответы тому, кому её отправят.
- Шаг «Объект не принят в работу» не является завершённой сделкой. Только карточка `C19` закрывает маршрут.

Основа содержания — памятка по сбору документов и [схема карточек в Google Документе](https://docs.google.com/document/d/1LZCWsBngz8m9RBifo7eznAERy0_LQJL02vCDiZRh004/edit). Списки помогают не пропустить вопросы, но окончательные требования к конкретной сделке согласуются с юристом и банком.
